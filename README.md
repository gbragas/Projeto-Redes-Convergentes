# Network QoS Simulation with ns-3

Simulation project developed with **ns-3.48** to study network Quality of Service (QoS) under different traffic loads and congestion conditions.

The main objective is to build a network simulation capable of generating datasets containing network metrics that can later be used for **Machine Learning models focused on QoS degradation detection and prediction**.

---

## Project Overview

The simulation represents a network with multiple clients communicating with servers through two routers connected by a bottleneck link.

```text
                    ┌───────────────┐
                    │   Client 0    │
                    └───────┬───────┘
                            │
                    ┌───────┴───────┐
                    │   Router 0    │
                    └───────┬───────┘
                            │
                    10 Mbps / 20 ms
                       BOTTLENECK
                            │
                    ┌───────┴───────┐
                    │   Router 1    │
                    └───┬───────┬───┘
                        │       │
                ┌───────┘       └───────┐
                │                       │
        ┌───────▼───────┐       ┌───────▼───────┐
        │   Server 0    │       │   Server 1    │
        └───────────────┘       └───────────────┘
```

There are currently:

* 4 clients
* 2 routers
* 2 servers
* 1 bottleneck link
* IPv4 routing
* UDP connectivity validation

The network will later support simultaneous **TCP and UDP traffic** with different traffic loads.

---

## Network Configuration

| Link                |   Data Rate |     Delay |
| ------------------- | ----------: | --------: |
| Client → Router 0   |    100 Mbps |      2 ms |
| Router 0 → Router 1 | **10 Mbps** | **20 ms** |
| Router 1 → Server   |    100 Mbps |      2 ms |

The Router 0 → Router 1 connection is intentionally configured as the **network bottleneck**.

This allows the simulation to reproduce congestion and QoS degradation as the amount of traffic increases.

## QoS Metrics

The final simulation will collect metrics such as:

### Throughput

Amount of data successfully received over time.

```text
Throughput = Received Bytes / Time
```

### Packet Loss

Number or percentage of packets that were transmitted but not successfully received.

```text
Packet Loss Rate =
    Lost Packets / Transmitted Packets
```

### Delay

Time required for a packet to travel from source to destination.

### Jitter

Variation in packet delay over time.

### Queue Size

Number of packets waiting in the bottleneck queue.

### Queue Delay

Time packets spend waiting in the bottleneck queue.

## Simulation Scenarios

The simulation will eventually generate multiple traffic conditions.

### Low Load

Traffic remains significantly below the bottleneck capacity.

```text
Traffic < 10 Mbps
```

Expected behavior:

* Low packet loss
* Low queue occupancy
* Low delay
* Low jitter

### Medium Load

Traffic approaches the bottleneck capacity.

```text
Traffic ≈ 10 Mbps
```

Expected behavior:

* Increasing queue occupancy
* Increasing delay
* Increasing jitter
* Possible packet loss

### High Load

Traffic exceeds the bottleneck capacity.

```text
Traffic > 10 Mbps
```

Expected behavior:

* Persistent queue buildup
* Increased delay
* Increased jitter
* Packet loss
* Reduced effective throughput

## Important Design Principle

The simulation should keep **traffic generation**, **network configuration**, **metric collection**, and **dataset generation** separated as the project grows.

The intended architecture is:

```text
              ┌────────────────────┐
              │ Scenario Generator │
              └─────────┬──────────┘
                        │
                        ▼
              ┌────────────────────┐
              │  Network Simulator │
              │       ns-3         │
              └─────────┬──────────┘
                        │
                        ▼
              ┌────────────────────┐
              │   QoS Monitoring   │
              └─────────┬──────────┘
                        │
                        ▼
              ┌────────────────────┐
              │   CSV Dataset      │
              └─────────┬──────────┘
                        │
                        ▼
              ┌────────────────────┐
              │ Machine Learning   │
              └────────────────────┘
```

This separation will make it easier to run thousands of simulations with different configurations and generate a consistent dataset.
